Developed a 2D maze/puzzle game engine with extensibility, internationalisation, and a custom input language

Features:
 Designed and parsed a custom domain-specific language (DSL) for game configuration files using ANTLR/JavaCC parser generation
 Implemented a plugin and scripting system with a defined Java API for plugins and scripts to interact with the game
 Applied full internationalisation (I18N) including
    locale switching using IETF language tags
    translatable UI text in English and one additional language
    locale-sensitive formatting for numbers, dates, and text
    correct Unicode handling
