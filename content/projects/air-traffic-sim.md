Developed a multithreaded air traffic simulation with a graphical user interface

Features:
 Multithreaded simulation using Java threads with blocking queues for inter-thread communication
 Thread pool to handle concurrent plane servicing tasks
 Thread-safe shared state with synchronisation to prevent race conditions and deadlocks
 Live statistics panel and flight event log
